# Gaslighters-SIH-2026
## Project Description

Gaslighters-SIH-2026 tackles corruption and inefficiency in India's MPLAD scheme, where ₹5 crore/year across 700+ MPs makes manual auditing nearly impossible. Our pipeline combines unsupervised anomaly detection (Isolation Forest) with supervised fraud risk scoring (XGBoost) to flag suspicious projects, while a contractor-MP graph layer detects hidden collusion patterns across constituencies. An LLM-powered explainability layer (via SHAP) translates risk scores into human-readable justifications, surfaced through a dashboard that ranks the riskiest projects for auditors to review first.
